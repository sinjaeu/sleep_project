# 수면 품질 예측기

## 프로젝트 소개

**수면 품질 예측기**는 사용자의 생활 습관, 신체 정보, 수면 습관 등 다양한 데이터를 바탕으로 수면의 질을 예측하고, 맞춤형 피드백을 제공하는 웹 기반 서비스입니다.  
이 프로젝트는 머신러닝 모델(Random Forest Regressor)을 활용하여 수면 점수를 예측하며, 사용자가 입력한 정보에 따라 수면 개선을 위한 구체적인 조언도 함께 제공합니다.

---

## 주요 기능

- **수면 품질 예측**: 사용자가 입력한 신체 정보, 생활 습관, 수면 습관 데이터를 바탕으로 수면 점수를 예측합니다.
- **맞춤형 피드백 제공**: 예측된 수면 점수와 입력 데이터를 분석하여, 카페인 섭취, 스트레스, 신체 활동, 수면 장애 등 다양한 측면에서 개선점을 안내합니다.
- **수면 건강 정보 제공**: 수면 부족이 건강에 미치는 영향, 다양한 수면 장애에 대한 정보를 제공합니다.
- **웹 기반 UI**: 누구나 쉽게 사용할 수 있는 직관적인 웹 인터페이스를 제공합니다.

## 데이터 설명

- **data/sleep_ef.csv, sleep_healthy.csv, SleepStudyData.csv, sleep_quality.csv**  
  다양한 출처의 수면 관련 데이터셋을 통합하여 사용합니다.  
  주요 컬럼: 신체 활동, 스트레스, BMI, 심박수, 수면 장애, 수면 시간, 아침 식사, 카페인 섭취 등

---

## 주요 파일 설명

- **app.py**  
  Flask 기반 웹 서버.  
  - `/` : 메인 페이지(수면 점수 예측 폼)
  - `/predict` : 입력값을 받아 수면 점수 예측 및 피드백 반환 (AJAX)
  - `/sleep_health` : 수면 건강 정보 페이지

- **main.py**  
  데이터 전처리, 피처 엔지니어링, 상관관계 분석, 모델 학습 및 저장

- **train.py**  
  데이터 분석, 시각화, 모델 성능 평가, 상관관계 그래프 생성

- **templates/index.html**  
  사용자 입력 폼, 예측 결과 및 피드백 모달, 상관관계 그래프 표시

- **templates/sleep_health.html**  
  수면 부족이 건강에 미치는 영향, 다양한 수면 장애 정보 제공

## 실행 방법

1. **필수 패키지 설치**
   ```bash
   pip install flask pandas scikit-learn joblib matplotlib seaborn
   ```

2. **모델 학습 및 저장**
   ```bash
   python main.py
   ```
   (필요시 `train.py`로 데이터 분석 및 시각화 가능)

3. **웹 서버 실행**
   ```bash
   python app.py
   ```
   브라우저에서 `http://localhost:5000` 접속

## 사용법

1. 메인 페이지에서 신체 정보, 생활 습관, 수면 습관 등 항목을 입력합니다.
2. "수면 점수 예측하기" 버튼을 클릭하면, 예측된 수면 점수와 맞춤형 피드백이 모달 창에 표시됩니다.
3. 상단 메뉴에서 "수면에 대하여"를 클릭하면, 수면 부족의 위험성과 다양한 수면 장애에 대한 정보를 확인할 수 있습니다.

## 예측 모델 및 피드백

- **모델**: Random Forest Regressor
- **입력 피처**: 신체 활동, 스트레스, BMI, 심박수, 수면 장애, 수면 시간, 아침 식사, 카페인 섭취 등
- **피드백 예시**:
  - 카페인 섭취가 높을 경우: "카페인 섭취가 높습니다. 카페인 섭취를 줄이세요."
  - 스트레스가 높을 경우: "스트레스가 높습니다. 이완 기법을 시도해보세요."
  - 수면 시간이 부족할 경우: "수면 시간이 너무 적습니다."
  - 수면 장애가 있을 경우: "수면 장애가 있습니다. 전문가와 상담하세요."
  - 등등
